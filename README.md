## ✦ О продукте

**BE'MOON** — это альтернативный взгляд на то, как люди находят мастеров в своем городе (барберов, тату-художников, керамистов, мебельщиков, шеф-кондитеров).

Большинство современных сервисов построены либо как сухие доски объявлений с бесконечным текстом, либо как громоздкие CRM-таблицы. В BE'MOON фокус смещен на **визуальный результат и личность мастера**:

* **Pinterest-style видеовитрина**: Живая динамическая лента работ (Masonry Feed) с кинетическим автовоспроизведением без тормозов и скачков интерфейса.
* **Эффект живого присутствия**: Прозрачные силуэты мастеров парят прямо над типографикой профиля на темном фоне с мягкой неоновой изумрудной аурой (3D Overlap).
* **Локальный контекст**: Быстрая фильтрация по районам города, радиусу и доступности «Только сегодня».
* **Прямой сценарий записи**: Минималистичный флоу бронирования слотов времени и диалоговый чат без лишних шагов.
* **Apple & Editorial эстетика**: Выверенная типографика (Syne + Plus Jakarta Sans), глубокая темная палитра (`#0d0e12`) и микро-анимации.

## 🧪 Экспериментальные функции (R&D)

* **Клиентский хромакей (Эксперимент)**: В процессе разработки прототипа потребовалось быстро делать прозрачные видео-аватарки без платных сторонних сервисов. Прямо в браузер была встроена экспериментальная студия вырезания фона с наложением кино-смаза (180° Shutter Blur) и CineBloom диффузии. Оставлена в прототипе как опциональный инструмент кастомизации профиля.

## 🛠 Технологический стек

* **Фреймворк**: React 19, TypeScript, Vite
* **Стилизация**: Tailwind CSS v4, Lucide Icons
* **Архитектура**: 100% Client-Side Self-Contained Prototype (полная автономность, моментальный запуск)
* **Деплой**: Готов к развёртыванию на Vercel Edge (`vercel.json`)

## 🚀 Запуск проекта

```bash
# Клонировать репозиторий
git clone https://github.com/username/bemoon.git

# Перейти в папку проекта
cd bemoon

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать production-билд
npm run build
```
